# VIP Tattoo — План курсу (плагін)

WordPress-плагін, що публікує інтерактивну 23-слайдову презентацію плану курсу як окрему, повністю незалежну сторінку (без хедера/футера/меню теми) — за тим самим принципом, що й основний плагін лендингу `vip-tattoo-landing`.

На сторінці рівно дві кнопки:
1. **«Открыть доступ к обучению»** — клік одразу створює оплату через Stripe/PayPal API (ключі й ціна — в «VIP Tattoo План: Оплата») і переадресовує на хостовану сторінку оплати провайдера. Ніякої форми на цьому сайті — email/телефон, якщо провайдер їх запитує, вводяться на його власній сторінці.
2. **«Написать Виктории»** — веде напряму в особистий Telegram Вікторії.

Після оплати провайдер сам переадресовує покупця в Telegram-бота, який надсилає повідомлення з доступом (текст налаштовується в «VIP Tattoo План: Оплата»). Окремо плагін слухає вебхуки Stripe/PayPal, щоб переслати підтверджену покупку в Meta Conversions API.

## Встановлення

1. Заархівуй папку `vip-tattoo-plan-viewer/` у `.zip`.
2. WordPress admin → «Плагіни» → «Додати новий» → «Завантажити плагін» → обери zip → «Встановити» → «Активувати».
3. Створи нову сторінку («Сторінки» → «Додати нову»), у боковій панелі «Атрибути сторінки» → «Шаблон» обери **«VIP Tattoo — План курсу (презентація)»**, опублікуй.

## Налаштування

В адмінці зліва з'являться три пункти меню:

**«VIP Tattoo План»**:
- **Кнопки** — текст обох кнопок, посилання другої кнопки (особистий Telegram).
- **SEO** — title, description, Open Graph, canonical, robots, JSON-LD Course schema.
- **Піксели / аналітика** — GA4, Google Tag Manager, Meta (Facebook) Pixel, TikTok Pixel. Кожен вмикається лише якщо заповнене відповідне поле. Клік по кнопці оплати шле подію Lead одразу в усі підключені пікселі (GA4: `generate_lead`, Meta: `Lead`, TikTok: `Lead`).
- **Вебхук** — на кожну подію (перегляд/клік оплати/клік «Написати») шле підписаний (HMAC-SHA256) POST-запит на вказаний URL (Zapier / Make / власна CRM).
- **Telegram-сповіщення** — надсилає повідомлення адміну в Telegram при кожному кліку на кнопку оплати.

**«VIP Tattoo План: Оплата»** — єдина сторінка з усім необхідним для прийому оплати:
- **Провайдер оплати** — Stripe або PayPal (перемикач; налаштування іншого провайдера нікуди не зникають).
- **Ціна / валюта / назва товару** — використовуються, коли Price ID (нижче) не задано — плагін сам створює одноразовий товар на льоту.
- **Stripe** — режим Test/Live, окремі Secret Key + Webhook Signing Secret + Price ID для кожного режиму (усі завжди залишаються збереженими), фото/опис товару (якщо Price ID не задано), текст біля кнопки оплати.
- **PayPal** — режим Sandbox/Live, окремі Client ID/Secret/Webhook ID для кожного.
- **Telegram-доступ** — окремий бот (Token + юзернейм + текст повідомлення з доступом), який пише клієнту одразу після оплати; незалежний від бота адмін-сповіщень вище.
- Адреси вебхуків показані прямо на сторінці — просто скопіювати в кабінет Stripe/PayPal.
- Внизу — таблиця **«Останні замовлення»**: лише дата/час і статус оплати, без email/телефону.

**«VIP Tattoo План: Оплата → Meta Conversions API»** (підменю) — серверна відправка події `Purchase` напряму в Meta, оскільки після оплати покупець одразу редиректиться в Telegram, а не назад на сайт, тому клієнтський піксель цю подію не бачить:
- **Pixel ID**, **Access Token** (з Events Manager → піксель → Conversions API), **Test Event Code** (опційно, для перевірки в «Тестирование событий»).
- Спрацьовує автоматично на кожну підтверджену оплату (хук `vip_tattoo_plan_purchase_confirmed`).
- Email/телефон (якщо провайдер їх передав) хешуються (SHA-256) і надсилаються в Meta — самі значення в базі даних логів не зберігаються.
- Внизу — таблиця останніх спроб відправки (ідентифікатор події, статус, сира відповідь Meta з `fbtrace_id`, час).

## Архітектура (коротко)

- `vip-tattoo-plan-viewer.php` — реєстрація шаблону сторінки, SEO/пікселі head-виводу, підстановка плейсхолдерів у `content/body-plan.html`.
- `includes/settings.php` — адмін-сторінка основних налаштувань (nonce + санітизація всіх полів).
- `includes/tracking.php` — таблиця подій, REST-роут `/vip-tattoo-plan/v1/track`, ідемпотентний інсерт (UNIQUE KEY на visit_token+event_type), вихідний вебхук, Telegram-нотифікація адміну.
- `includes/payments.php` — адмін-сторінка «Оплата» (Stripe/PayPal ключі, ціна/товар, Telegram-доступ), таблиця замовлень, REST-роути створення чекауту / повернення / вебхуків обох провайдерів, доставка доступу через Telegram-бота, хук `vip_tattoo_plan_purchase_confirmed` для сторонніх інтеграцій (Meta CAPI нижче).
- `includes/meta-capi.php` — Meta Conversions API: надсилає `Purchase` на хук `vip_tattoo_plan_purchase_confirmed`, власна таблиця логів спроб відправки, підменю налаштувань під «VIP Tattoo План: Оплата».
- `templates/vip-tattoo-plan-viewer.php` — сама сторінка (повністю самодостатня, без залежності від теми).
- `content/body-plan.html` — розмітка усіх 23 слайдів з плейсхолдерами (`{{ASSET_URL}}`, `{{CTA_PRIMARY_TEXT}}`, `{{CTA_SECONDARY_TEXT}}`, `{{CONTACT_URL}}`).
- `css/plan-viewer.css` — стилі презентації (ідентичні `docs/index.html`).
- `js/track.js` — клієнтський трекер (view/checkout_click/contact_click + піксель-виклики, зокрема Lead на клік оплати).
- `js/checkout.js` — клік по кнопці оплати викликає `create-checkout` (без форми) і переадресовує на сторінку оплати Stripe/PayPal.
- `assets/slides/`, `assets/icons/` — зображення слайдів та іконок, вбудовані в плагін (не залежить від папки `docs/`).

Ця гілка (`wp-plugin-development`) розробляється незалежно від гілки `pdf-plan-development` — зміни тут не зачіпають сам PDF-файл в іншій гілці.
